# DataMotion 动效编辑器开发记录

本文档用于记录 DataMotion 动效编辑器每天完成的功能、界面调整、验证结果和后续事项。

记录约定：

- 按日期倒序追加开发记录。
- “已完成”只记录已经在当前代码中实现的内容。
- “验证结果”记录实际完成的构建和浏览器检查。
- “当前边界”用于说明现阶段真实能力，避免后续对功能产生误解。
- 详细视觉验收截图及数据保存在项目根目录的 `design-qa.md`。

---

## 2026-07-23

### 今日目标

- 将“动效预设”首页搜索改为同时覆盖基础动效与装饰组件的全局案例搜索。
- 暂时从界面中移除“项目交付”，保留已有代码以便后续恢复。
- 明确自定义素材的保存位置，并统一基础动效编辑页的分类名称。
- 修正 SVG 导入展示、重复导出入口和数字参数步进按钮样式。
- 优化强调与告警动效表现，并精简基础动效分类。

### 已完成

#### 1. 首页全局案例搜索

- 搜索框提示文字改为“搜索基础动效和装饰组件”。
- 未输入关键词时仍展示原有 10 个精选基础动效，不改变首页默认内容。
- 输入关键词后搜索全部 15 个基础动效和 11 个装饰组件，共 26 个案例。
- 搜索字段包含中文名称、英文名称、说明和使用场景。
- 基础动效结果继续使用真实动效预览，点击后进入对应基础动效编辑页。
- 装饰组件结果使用装饰组件自身的生成代码实时预览，点击后进入对应装饰组件编辑页并自动选中目标效果。
- 修正了装饰组件在单条搜索结果卡片中的预览居中问题。

#### 2. 导航与名称调整

- 暂时移除左侧“项目交付”入口及对应页面切换逻辑。
- `ProjectDelivery.vue` 和原有项目交付实现仍保留在项目中，后续需要时可以重新接回导航。
- 基础动效编辑页左侧标题由“全部动效”改为“基础动效”；进入具体分类后仍显示当前分类名称。

#### 3. 自定义素材保存位置确认

- 自定义 CSS 素材保存后显示在“自定义素材”页面左侧的素材列表中。
- 保存数据写入当前浏览器、当前站点的本地存储，键名为 `visual-motion-custom-css-assets`。
- 这类素材不会上传服务器，也不会自动写入电脑文件夹；更换浏览器、端口、设备或清理站点数据后不会自动同步。

#### 4. SVG 导入与编辑控件修正

- 基础动效导入 SVG 后，主预览只显示导入的 SVG 内容，不再显示原有示例卡片的背景、边框和阴影。
- 当前选中的基础动效仍会应用到导入的 SVG 上。
- HTML、Vue 和 JSON 导出结果同步使用纯 SVG 展示结构，不再包含“数据态势”等示例内容。
- 移除顶部工具栏中与编辑区“导出 HTML”重复的“导出”按钮。
- 保留各编辑区内部的“导出 HTML”和“复制代码”操作。
- 去除装饰组件所有数字参数下调按钮的边框与阴影，避免出现白色小框。

#### 5. 基础动效优化与分类精简

- “高亮发光”改为蓝色主体亮度、饱和度和多层外光晕同步呼吸，强化整体高亮感。
- “边框高亮”改为深色内部保持稳定，仅让边框亮度、内光和外光周期变化，不再使用流光扫过效果。
- “脉冲扩散”改为中心发光点配合两层错峰圆环扩散，扩大可见范围并提高辨识度。
- 预览组件与 HTML / Vue 导出代码同步使用新的三套动效实现。
- 删除“大屏装饰”分类。
- 将“边框流光”和“扫描线”移动到“强调动效”。
- 删除内置动效“地图光点闪烁”。
- 基础动效总数由 16 个调整为 15 个，“强调动效”现包含 5 个效果。
- 装饰组件和 SVG 流光保存到“我的动效”时，分类统一记录为“强调动效”。

### 验证结果

- Edge 验证首页默认展示 10 个案例，左侧仅显示“动效预设、装饰组件、我的动效、自定义素材”。
- 搜索“星环粒子底座”只返回 1 个装饰组件结果，实时预览和居中显示正常，点击后正确进入并选中“星环粒子底座”。
- 搜索“放大提示”只返回 1 个基础动效结果，点击后正确进入“放大提示”，左侧标题显示“基础动效”。
- Edge 实际导入 SVG 后，预览目标边框为 `0px`、背景为透明、阴影为 `none`，示例文字已移除。
- 顶部操作区只保留“导入动效”和“保存到我的动效”。
- 装饰组件 5 个数字参数下调按钮的四边描边均为 `0px`，阴影为 `none`。
- Edge 验证基础动效分类仅保留“全部、入场动效、循环动效、强调动效、告警动效”，页面中不存在“大屏装饰”。
- “强调动效”显示 `5 / 15`，包含“放大提示、高亮发光、边框高亮、边框流光、扫描线”。
- 页面与搜索数据中均不存在“地图光点闪烁”。
- “高亮发光”和“边框高亮”使用独立动画，“脉冲扩散”显示 22px 中心点和两层扩散圆环。
- 浏览器控制台无脚本错误，网络请求无失败。
- Vite 生产构建通过；仅保留既有的 JavaScript 主包体积提示。

### 当前边界

- 目前的“全局搜索”覆盖编辑器内置的基础动效和装饰组件，不搜索“我的动效”与自定义 CSS 素材。
- “项目交付”只是从界面和当前路由中隐藏，并未删除实现文件或清理相关代码。
- 自定义素材仍为单机浏览器本地数据，没有账号、云同步或跨设备共享能力。

### 提交状态

- 今日确认的界面、动效、搜索、SVG 导入和分类调整已整理为本地 Git 提交。
- 本机 Edge 验收脚本、临时截图和 Codex 本地配置不进入仓库。

## 2026-07-22

### 今日目标

- 将首页和编辑器内页统一为克制的黑白灰设计工具风格。
- 恢复蓝色动效和蓝色主要操作按钮。
- 让首页卡片、动效缩略图和编辑预览保持一一对应。
- 为所有动效预览建立统一的像素格画布。

### 已完成

#### 1. 首页与编辑器视觉统一

- 首页改为动效案例展示页，保留搜索、悬停预览和点击进入编辑的核心流程。
- 首页卡片调整为桌面端四个一排。
- 首页卡片不再使用模糊截图，改为与编辑器共用的实时矩形动效预览。
- 首页卡片与对应基础动效 ID 一一绑定，进入编辑器后展示同一个动效。
- 基础动效、装饰组件、我的动效、自定义素材和项目交付统一为首页的黑白灰视觉体系。
- 首页和编辑页的左侧一级导航、品牌位置和文字样式保持一致。
- 移除基础动效主预览底部的播放、倍速、分辨率和全屏工具条。

#### 2. 蓝色视觉恢复

- 基础动效默认主色统一为 `#0070F3`。
- “保存到我的动效”和各模块的重要操作按钮恢复为蓝色。
- 装饰组件 4 个分类、11 个动效全部统一为蓝色系。
- 装饰组件的参数默认值、列表缩略图、实时预览和导出代码保持颜色一致。
- SVG 流光采用三段蓝色：亮蓝 `#7AB8FF`、主蓝 `#0070F3`、深蓝 `#003B82`。
- 彗星、线性流光和粒子动效中的可见高光由白色改为浅蓝色。

#### 3. 统一像素格画布

- 建立公共预览画布样式 `dm-motion-canvas`。
- 像素格规格统一为：
  - 网格尺寸：`18 × 18px`。
  - 网格线：`1px` 低透明白线。
  - 画布底色：`#111111`。
- 已覆盖以下区域：
  - 首页 10 个动效案例。
  - 基础动效 16 个列表缩略图。
  - 基础动效主预览画布。
  - 装饰组件 11 个列表缩略图。
  - 装饰组件主预览画布。
  - 自定义素材预览画布。
  - “我的动效”预览卡片容器。
- 后续新增动效只要复用标准预览组件或 `dm-motion-canvas`，即可自动继承像素格背景。
- 像素格属于编辑器预览视觉；导出的独立 HTML 仍保持干净黑色背景。

#### 4. 当前数据与交付流程确认

- 项目继续采用本地优先模式，不增加账号、云同步和后台数据库。
- “我的动效”保存在当前浏览器本地，内容包含名称、HTML、预览 PNG 和相关参数快照。
- 自定义 CSS 素材使用独立的浏览器本地存储。
- 项目交付继续支持打开本地文件夹，以及导入单个 HTML 或 ZIP。
- 项目交付会识别 HTML 入口、构建文件树、检查相对资源、生成隔离预览，并下载保留原目录结构的 ZIP。

### 验证结果

- Edge 自动检查首页 10 个动效案例，全部使用统一像素格。
- Edge 自动检查基础动效 16 个缩略图和主预览，全部通过。
- Edge 自动遍历装饰组件 4 个分类、11 个动效，蓝色和像素格均通过。
- 自定义素材画布和已有“我的动效”卡片检查通过。
- 浏览器控制台没有脚本错误。
- 没有失败的网络请求。
- `vue-tsc --noEmit` 与 Vite 生产构建通过。
- 生产构建仍有 JavaScript 主包超过 500 kB 的提示，不影响当前功能。

### 当前边界

- “我的动效”与“项目交付”目前尚未自动打通。
- 保存到“我的动效”的内容不会自动进入项目交付列表。
- 项目交付打开本地文件夹时只读取文件，不会写回原文件夹。
- “新建项目”只创建浏览器中的空工作区，不会在电脑上创建真实文件夹。
- 导入的项目文件主要保存在当前页面内存中，刷新后不会完整恢复。
- 项目交付中的复选框当前只改变选择状态，不会控制整包下载范围。
- 基础动效保存后可以预览和下载，但还不能从“我的动效”恢复全部参数继续编辑。
- 普通装饰动效保存了参数快照，但目前只有 SVG 流光提供明确的“再次编辑”入口。
- 顶部全局搜索目前主要接入基础动效列表，其他模块尚未完整接入。
- 浏览器本地存储包含 HTML 和 PNG，记录过多时可能受到浏览器容量限制。

### 后续建议

- 打通“我的动效 → 项目交付”，让已保存动效可以直接加入指定板块。
- 为项目交付增加项目持久化和重新打开能力。
- 明确复选框用途，支持“只下载选中动效”或移除无效选择状态。
- 为基础动效和普通装饰动效增加“再次编辑”。
- 根据模块拆分生产代码，降低首屏 JavaScript 包体积。

### 提交状态

- 今日修改保留在本地工作区，尚未提交 Git。
