记录约定：

- 按日期倒序追加开发记录。
- “已完成”只记录已经在当前代码中实现的内容。
- “验证结果”记录实际完成的构建和浏览器检查。
- “当前边界”用于说明现阶段真实能力，避免后续对功能产生误解。
- 详细视觉验收截图及数据保存在项目根目录的 `design-qa.md`。

### 当前边界

- “我的动效”与“项目交付”目前尚未自动打通。
- 保存到“我的动效”的内容不会自动进入项目交付列表。
- 项目交付打开本地文件夹时只读取文件，不会写回原文件夹。
- “新建项目”只创建浏览器中的空工作区，不会在电脑上创建真实文件夹。
- 导入的项目文件主要保存在当前页面内存中，刷新后不会完整恢复。
- 项目交付中的复选框当前只改变选择状态，不会控制整包下载范围。
- 基础动效保存后可以预览和下载，但还不能从“我的动效”恢复全部参数继续编辑。
- 普通装饰动效保存了参数快照，但目前只有 SVG 流光提供明确的“再次编辑”入口。
- 顶部全局搜索目前主要接入基础动效列表，其他模块尚未完整接入。
- 浏览器本地存储包含 HTML 和 PNG，记录过多时可能受到浏览器容量限制。
