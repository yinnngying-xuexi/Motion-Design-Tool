# DataMotion 动效编辑器开发记录

本文档用于记录 DataMotion 动效编辑器每天完成的功能、界面调整、验证结果和后续事项。

记录约定：

- 按日期倒序追加开发记录。
- “已完成”只记录已经在当前代码中实现的内容。
- “验证结果”记录实际完成的构建和浏览器检查。
- “当前边界”用于说明现阶段真实能力，避免后续对功能产生误解。
- 详细视觉验收截图及数据保存在项目根目录的 `design-qa.md`。

## 2026-08-07

### 本周目标

- 完成“星环粒子底座”第一阶段的分层 SVG 替换与复用流程，让系统预设素材和用户导入素材共用逐图层编辑、预览和导出能力。
- 提高 Figma 导出 SVG 的图层识别稳定性，并解决假透视环形素材无法直接进行普通二维旋转的问题。

### 已完成

- 将用户确认的分层 `star-ring.svg` 接入为星环粒子底座系统预设，移除旧的程序绘制底座，缩略图、主预览和导出共用同一份真实素材。
- 重新整理实际素材图层：界面显示 SVG 原始英文名称、对应中文角色和眼睛开关；各图层可以独立显示隐藏并配置动效。
- 保留分层 SVG 导入后的“图层识别与动效映射”弹窗，统一为暗色视觉，并允许确认或手动修正自动映射结果。
- SVG 解析改为优先读取素材根分组的直属图层，支持具名 `g` 和直属矢量形状，避免把 Figma 内部的光效、蒙版、Union、Vector 等技术节点错误提升为顶层素材图层。
- 图层名称读取兼容 `id、data-name、aria-label、title` 等常见来源，并过滤 Figma 自动生成的裁剪、滤镜、渐变和编号名称；兼容 `outer-ring` 与 `out-ring`。
- 装饰组件图层可以直接引用已支持的基础动效参数和关键帧，预览时长会读取当前图层实际使用的基础动效时长。
- 保留编辑器系统粒子层，支持眼睛开关和粒子强度调节；导入 SVG 后仍可继续叠加星环粒子效果。
- `inner-ring` 的环形高亮轮转同时支持：直属分段、Figma 子分组内分段，以及未分段连续路径的移动高亮遮罩兼容方案。
- 连续路径轮转不会旋转已经做好的假透视几何，只移动高亮及渐隐拖尾；顺时针和逆时针会同步调整运动方向与拖尾方向。
- 明确 Figma 稳定制作规范：轮转分段使用 `segment-01、segment-02…`，静态底环使用 `ring-base`，推荐 12–16 个分段。
- 更新星环缩略图位置、映射确认后的配置重建以及真实素材图层名称保留逻辑。

### 验证结果

- 使用真实的 `星环.svg、底座2.svg、底座3.svg` 检查了不同 Figma 导出结构，包括直属形状、嵌套分组、蒙版和连续路径。
- 当前生产构建已通过：`vue-tsc --noEmit` 和 Vite 构建均无错误。
- 本地预览服务 `http://127.0.0.1:5173/` 返回正常；已有的主包体积提示不影响当前功能。
- 本周修改未包含 `daily-task-widget-build-*` 临时目录，也未改动首页、基础动效业务流程、自定义素材和项目交付模块。

### 当前边界

- 分段 SVG 的轮转效果最稳定；连续路径只能通过移动高亮遮罩模拟，不能获得与设计师逐段控制完全相同的细节。
- 解析规则更新后，已经导入到当前页面内存中的旧素材需要重新导入一次，才能写入新的图层和高亮识别信息。
- Figma 导出时需要保留 `id` 属性；如果分段被 Flatten、Union 成单一路径，编辑器无法恢复原来的设计分段。

### 下周建议

- 在 Figma 中制作一版规范化的 `inner-ring / ring-base / ring-segments / segment-*` 测试素材，建议使用 12–16 个假透视分段。
- 完整验证“导入 → 自动映射 → 逐图层动效 → 保存 → 复制代码 → 导出 HTML”，重点比对预览与导出效果。
- 星环流程稳定后，再确定第二种经典装饰组件模板，不强行复用星环的固定图层结构。

### 提交状态

- 本周编辑器代码、系统预设 SVG、产品规则、视觉验收记录和本开发记录随本次 Git 提交同步。

## 2026-08-03

### 今日目标

- 重构装饰组件中“星环粒子底座”的产品与实现逻辑，使系统预设和项目分层 SVG 共用同一套动效结构。
- 保留原有蓝色星环底座视觉，同时让导入素材可以按图层独立调整、保存与导出。

### 已完成

- 为星环底座建立“背景层、静态环层、旋转环层、中心层、粒子层”五类标准角色。
- 新增“整体 / 图层”参数切换；整体支持尺寸、位置、透明度和主色，图层支持显示隐藏、颜色样式、透明度与专属动效参数。
- 分层 SVG 导入会读取完整 `g` 图层树和 `id`，根据中英文别名自动匹配五类角色。
- 自动匹配不完整时提供手动映射弹窗；一个角色可以绑定多个 SVG 分组，未映射图层默认关闭。
- 只有整体图形、没有有效分组的 SVG 按整体素材处理。
- SVG 导入继续执行安全清理，移除脚本、事件属性、外部资源和不安全节点。
- 保存、复制代码和导出 HTML 会保留内联 SVG、图层映射、图层顺序、整体参数和全部图层动效参数。
- 新增“保存为自定义组件”，保存后的分层装饰组件显示在装饰组件左侧列表，并存储在当前浏览器本地。
- “保存到我的动效”同步保存星环完整配置，预览时长根据当前可见动画图层计算。
- 恢复原有扁平星环底座风格：旋转环在圆形坐标系中旋转，外层统一水平压扁，旋转过程中不会竖立。
- 按参考图重新校准主环、中心层和下层轨道的中心、比例、纵深与光晕关系。
- 粒子改为不规则分布，不同粒子拥有独立的位置、大小、透明度、漂浮距离、周期和延迟。
- 删除静态环左右两侧超出轮廓的多余线段。
- 中心层改为深蓝线性渐变，默认整体透明度调整为 `0.7`。

### 验证结果

- Microsoft Edge 在 `1600 × 900 / DPR 1` 下完成多轮截图检查与参考图并排比较。
- 浏览器确认静态环多余 Path 数量为 `0`。
- 浏览器确认中心层计算样式为线性渐变，默认透明度为 `0.7`。
- 系统预设、缩略图和主预览均保持水平星环结构；粒子在不同时间点呈现不同可见组合。
- `vue-tsc --noEmit` 与 Vite 生产构建通过；仅保留既有的主包体积提示。
- 本轮未改动基础动效、首页、自定义 CSS 素材和项目交付逻辑。

### 当前边界

- 编辑器运行时目前通过 SVG 文件导入素材，尚不支持用户直接粘贴 Figma 链接导入。
- 开发阶段可以使用包含 `node-id` 的 Figma 具体编组链接接入新的系统预设。
- 自动识别依赖 SVG 分组和图层名称；名称不规范时需要在映射弹窗中手动指定角色。
- 星环五层角色适用于环形、底座类素材；完全不同的装饰类型需要建立自己的角色模板，不强行复用星环结构。

### 明日建议

- 使用一个真实 Figma 分层底座导出 SVG，完整验证“自动识别 → 手动修正 → 图层参数 → 保存 → 导出 HTML”流程。
- 优化自动识别优先级：优先匹配顶层标准角色组，再把其子图层作为整体结构保留，减少复杂 SVG 的映射噪音。
- 确认 Figma 图层命名规范并制作一份可复用模板，建议顶层使用 `background、static-ring、rotating-ring、center、particles`。
- 在星环流程稳定后，再确定第二种经典装饰组件模板，不将所有素材强行套用同一套五层结构。

### 提交状态

- 本次记录随当前功能改动一并提交；最终推送结果以 GitHub 远程仓库状态为准。

## 2026-07-30

### 今日目标

- 统一所有动效预览区域底部的播放排版，不调整页面其他布局和视觉。
- 所有模块统一采用入场动效的紧凑控制，只显示“重播 + 当前时长”。
- 为“呼吸、上下浮动、轻微闪烁、慢速旋转”建立专属循环参数，移除无关的通用 CSS 参数。
- 完善外部 SVG 素材的统一支持，并新增“光效脉冲”循环动效。

### 已完成

- 基础动效、装饰组件、自定义素材、图标底座和“我的动效”预览全部接入同一套紧凑播放控制。
- 所有预览控制均删除暂停、继续、倍速、进度条、当前/总时间和循环入口。
- 控制区只保留“重播”按钮与当前动效时长，点击后从动画起点重新播放。
- 紧凑控制宽度随内容收缩，居中显示，高度固定为 `36px`；时长保留实际精度，例如 `0.65s`。
- 基础动效时长随当前专属参数同步；装饰组件读取当前效果时长；自定义素材读取 CSS 时长变量；图标底座与“我的动效”读取各自保存的动效时长。
- 修改基础动效右侧参数后，继续按既有规则自动重新播放一次。
- 统一“上滑进入、左滑进入、缩放进入”的基础参数：时长 `0.2–2s / 0.05s`，延迟 `0–2s / 0.05s`，默认缓动 `ease-out`。
- 上滑进入使用 `0–160px / 4px` 的纵向进入距离，默认 `36px`，从下方移动到最终位置。
- 左滑进入改为从右侧进入，使用 `translateX(36px) → translateX(0)`，距离范围与上滑进入一致。
- 缩放进入默认起始缩放改为 `0.85`，范围 `0.7–1 / 0.01`；结束缩放和结束透明度固定为 1。
- 三个动效的滑块拖动只实时更新参数，松开后以 `150ms` 防抖重播一次；输入框在 Enter 或失焦后重播。
- 点击重置会恢复当前动效默认值并重播一次。
- 页面主体、左右栏、参数表单、导出和保存逻辑均未调整。
- 四个循环动效统一按“基础参数 → 效果参数”排列，并固定为无限循环。
- “呼吸”只保留循环时长、开始延迟、缓动曲线和最小缩放；默认在 `scale(0.96)` 与 `scale(1)` 间循环。
- “上下浮动”只保留循环时长、开始延迟、缓动曲线和浮动距离；默认按 `0 → -8px → 0` 循环。
- “轻微闪烁”只保留循环时长、开始延迟、缓动曲线和最低透明度；最高透明度固定为 1。
- “慢速旋转”只保留循环时长、开始延迟和旋转方向；缓动固定为 `linear`，顺逆时针分别导出 `360deg` 与 `-360deg`。
- 四个循环动效在滑块拖动时实时更新，松开、输入确认、方向切换或重置后以 `150ms` 防抖重新开始预览。
- 切换动效时会销毁上一预览节点并启动当前动画，避免多个循环动画同时运行。
- 基础动效和装饰组件编辑区的“导入动效”统一改为“导入 SVG”，图标由向上箭头改为向下导入图标，原有文件选择逻辑保持不变。
- “轻微闪烁”循环时长范围调整为 `0.8–5s`，最低透明度默认改为 `0.75`，最高透明度继续固定为 1。
- 新增“光效脉冲”：默认 `2s / 0s / ease-in-out`，提供光效颜色、`50%` 光晕强度和 `18px` 光晕范围。
- 光效脉冲未导入 SVG 时使用品牌蓝；导入 SVG 后默认从素材中检测并继承第一个有效主色。
- 基础动效预览统一将动画绑定到素材外层容器；未导入时显示默认矩形，导入后在同一容器中用内联 SVG 替换默认矩形。
- SVG 解析会移除脚本、事件属性、`foreignObject`、嵌入页面和外部资源引用，并保留安全的内联图形元素。
- 导入 SVG 后显示可折叠“SVG 样式”区域，支持“保留原色 / 单色覆盖”、填充色、描边色、描边宽度和基础透明度。
- 多色 SVG 默认保留原色；选择单色覆盖后才显示填充色和描边色。
- SVG 样式状态独立于各动效参数，切换动效时不会重置；装饰组件的一般 SVG 组合预览也接入同一套样式控制。
- 复制代码和导出 HTML 会带上安全清理后的内联 SVG、当前 SVG 样式和当前动效代码。

## 2026-07-29

### 今日目标

- 解决基础动效右侧参数全部相同、部分参数与当前动效无关的问题。
- 让参数面板、实时预览和导出代码使用同一套动效配置。
- 保留现有暗色编辑器布局和蓝色视觉，不改动核心操作流程。

### 已完成

- 为 15 个基础动效分别建立独立参数结构，不再渲染固定的通用参数全集。
- 参数面板按“效果参数”和“时间与节奏”动态显示，当前动效没有实际用途的参数不会出现。
- 入场动效分别提供透明度、模糊、位移或缩放参数；循环动效分别提供呼吸范围、浮动高度、闪烁范围或旋转参数。
- 强调与告警动效分别提供高亮光晕、边框高亮、告警频率、脉冲层数、流光头尾和扫描方向等专属参数。
- “边框流光”支持流光长度、头尾透明度、头尾线宽、光晕和方向调节。
- “扫描线”支持四个扫描方向、线宽、长度、光晕和扫描周期调节。
- “脉冲扩散”支持起始半径、扩散半径、扩散层数、层间间隔和线宽调节。
- 每个动效在当前编辑会话中单独记忆参数；切换到其他动效再返回时，已调整值不会被重置。
- “重置”只恢复当前动效的默认参数，不影响其他动效。
- 导入 SVG 后才增加“素材适配”参数组，提供素材缩放、水平位置和垂直位置；未导入素材时不显示。
- 实时矩形预览、导入 SVG 预览和 HTML/CSS 导出均改为读取新的专属参数。
- 更新了保存数据的兼容类型，已有装饰组件和 SVG 流光保存记录仍可读取。

### 验证结果
