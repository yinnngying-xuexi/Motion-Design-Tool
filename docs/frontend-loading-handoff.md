# 纯代码光效前端接入

适用于粒子摆动、流体线框环、粒子辉光环、星芒光点、电弧光束、粒子光带。六款均为程序化重建，不使用 GIF、WebP、Base64 图片或序列帧。

## 给前端交付什么

1. 调整颜色、整体缩放；有文字的 loading 不需要文字时，关闭「显示文字」。
2. **直接预览**：点击「导出 HTML」，下载一个可离线播放的完整文件。
3. **项目接入（推荐）**：点击「导出 HTML」右侧下拉箭头，选择「下载前端源码 ZIP」。解压后得到：

   - `index.html`：当前组件结构和独立演示页面。
   - `effect.css`：当前组件样式。
   - `effect.js`：当前效果的着色器与共用最小运行器。
   - `README.md`：前端接入和控制说明。

三种交付方式（复制代码、独立 HTML、源码 ZIP）使用同一份当前参数和渲染逻辑，不需要安装 Vue、Element Plus 或 DataMotion 编辑器。

## 放入大屏项目

- 直接嵌入：只取 `index.html` 中的动效容器，加载 `effect.css` 和 `effect.js`；不要复制演示页面的 `html/body` 黑底样式，组件自身背景透明。
- iframe 接入：保持源码包文件相邻，加载 `index.html`。叠放在大屏上时，将演示页背景改为 `transparent` 并移除 iframe 边框。
- Vue/React：不要仅通过 `v-html` / `innerHTML` 插入带 script 的字符串。将运行器作为普通项目脚本执行，动态挂载的 `dm-light-renderer` 会初始化。移除 DOM 时自动释放 GPU 资源。
- 多实例：每个节点独立读取 `data-color`、时长和尺寸，不使用共享 SVG 滤镜 ID。加载不同效果的脚本会合并效果注册，不覆盖之前的效果；接入多个源码包时请避免同名 CSS/JS 文件覆盖。

## 代码为什么仍有一定长度

现在保留的是实际光效计算逻辑及运行器，包括编译着色器、处理大小变化、暂停隐藏页面和离屏元素、释放资源等；没有大段编码后的图片数据。导出只包含当前案例的着色器，不打包其他光效或编辑器界面。

程序化重建参考形态、节奏和发光层次，不是原 GIF 的逐帧一致复刻或 AE 源文件。浏览器必须支持 WebGL；不可用时显示提示，不静默换回图片。请在目标大屏设备检查性能和浏览器策略。严格 CSP 环境需按项目规范授权脚本和样式；可使用分离源码文件，内联参数样式也需要按项目策略处理。

此前保存到「我的动效」的旧图片版成果不会自动改变；需要新版时从编辑器重新保存或重新导出。
