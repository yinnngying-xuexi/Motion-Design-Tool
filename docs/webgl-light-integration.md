# WebGL 光效交付说明

适用：通用装饰中的「等离子光环」「柔光波带」。其他案例的原 SVG/CSS 交付不变。

## 设计与使用

- 两款光效是参考 GIF 的程序化重建，不是 GIF 播放器，也不承诺像素级还原。
- 内容背景透明，可以独立叠放在标题、按钮或图表附近；HTML 示例页面的黑底只是展示背景。
- 在编辑器调整颜色、强度、循环时长、静态/播放状态、整体等比缩放；光环还支持正反方向。
- 柔光波带支持「波带弧度」0%–100%，默认 22%；「起伏数量」1–4 组，默认 2 组。默认颜色 #35C9DB、强度 77%、循环 5.05s，处于播放状态。五层不等跨度的透明薄带交错流动，局部细亮边、低透明薄带面与微细网点随层次舒展，不固定为单个 S 弯，也不使用等宽等幅的平行正弦线。0% 弧度为平直光带，100% 为较大起伏，调整不改变光带厚度与整体尺寸。复制与导出保留当前参数，重置恢复对应默认值。
- 缩略图、主预览、复制代码、导出 HTML、保存成果使用同一套渲染逻辑。

## 前端接入

1. 使用「导出 HTML」可得到包含 HTML、CSS、着色器与最小初始化脚本的完整文件。直接打开即可验证，不需要网络素材或第三方库。
2. 使用「复制代码」时须保留三个部分：装饰节点、样式、初始化脚本。不要只复制 `canvas`。
3. 普通 HTML：保留代码中的初始化脚本即可。同页多份光效会复用注册逻辑，各自独立渲染。
4. Vue/React：节点挂载后执行交付代码中 `<script>` 内的初始化代码，例如放入 `onMounted` / `useEffect`。样式单独保留。仅通过 `v-html` / `innerHTML` 插入完整代码不会自动执行脚本，因而不能只用这种方式接入。不要使用 `eval` 执行外部不可信内容。
5. 如果项目采用禁止内联脚本的 CSP，将初始化代码放入项目自身的脚本模块，遵守该项目的 CSP；不要为此放宽全局安全策略。

不要给外层裁剪容器增加不必要的黑底；保持素材比例，避免单独拉伸宽高。编辑器的网格和预览背景不会进入交付代码。

## SVG 边界

两款效果使用实时像素光纹理，不能等价转成动态纯 SVG。「复制 SVG」在编辑器及已保存列表中禁用，并提示改用代码或 HTML。不要将 Canvas 的静态截图当作可编辑动态 SVG 交付。

## 运行与性能

- 需要浏览器支持 WebGL；不支持或上下文丢失时显示提示，不偷偷替换为不同的简易效果。
- 光效离开视口、页面隐藏、进入静态状态或强度为零时停止动态帧；节点移除时释放图形资源。
- 默认根据显示尺寸与设备像素比渲染，并限制最大渲染尺寸，避免大屏放大产生无限显存开销。
- 多个复杂光效同时使用前，应在实际大屏设备检查流畅度、显存和透明叠加效果。浏览器截图验证不等于所有现场设备的性能保证。
- 保存列表预览只安装应用内可信渲染器，原有 iframe 安全隔离保持不变，不执行任意保存脚本。
